Відео шпалери (Android, Kotlin)

Що вміє
- Додавати одне або кілька відео, вони крутяться по колу як живі шпалери.
- Кнопка в застосунку вмикає і вимикає звук. За замовчуванням звук вимкнено.
- Відео копіюються у пам'ять застосунку, тому не зникнуть, якщо видалити оригінал.
- Коли екран вимкнено або шпалер не видно, відео стоїть на паузі, щоб не гріти телефон.
- Зламаний файл пропускається, решта відео грають далі.

Як зібрати APK
1. Встановити Android Studio (будь-яка свіжа версія) і відкрити цю папку як проєкт.
2. Дочекатись Gradle Sync. Якщо Studio запропонує оновити Gradle або плагін Android, погодитись.
3. Меню Build, пункт Build Bundle(s) / APK(s), потім Build APK(s).
4. Файл знайдеться в app/build/outputs/apk/debug/app-debug.apk. Скинути його на телефон і встановити.

Мінімальна версія Android: 8.0.

Для плавної роботи краще брати відео до 1080p і до 30 fps.
